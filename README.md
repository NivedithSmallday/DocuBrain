# Smallday Docubrain

**Smallday Docubrain** is a lightweight, high-accuracy, self-hosted AI system focused on **retrieval-first intelligence**.

---

## ⭐ Core Features

### 🔍 RAG + Advanced Search

* Hybrid search:

  * Semantic (embeddings)
  * Keyword (BM25)
  * Optional Knowledge Graph
* Works on PDFs, Docs, Excel, CSV
* Grounded answers (no guessing)
* Scales to millions of documents

---

### 🔬 Deep Research Mode

* Multi-step reasoning
* Query rewriting & decomposition
* Multi-source retrieval
* Final synthesized answers

---

### 🤖 AI Agents

* Custom agents with:

  * Instructions
  * Knowledge
  * Tools (MCP)
* Can retrieve data and execute actions

---

### ⚙️ Actions / MCP

* API calling
* Workflow automation
* External system integration

---

### 🔗 Connectors

* Google Drive
* GitHub

---

### 👥 Collaboration

* Chat sharing
* User roles (Admin, Curator, User)
* Feedback & basic analytics

---

### 🔐 Enterprise

* SSO (OIDC, SAML, OAuth2)
* RBAC
* Document-level permissions

---

### 🧠 LLM Support

* Ollama
* vLLM

---

### 🐳 Deployment

* Docker-based
* Minimal and self-hosted



## 🎯 Goal

A clean, scalable AI system built for **accurate retrieval, intelligent agents, and real-world data understanding**.
